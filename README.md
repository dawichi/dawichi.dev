# dawichi.dev

Personal site and portfolio of David M. Fajardo, live at [dawichi.dev](https://dawichi.dev).

Built with [Astro](https://astro.build) and Tailwind CSS v4. It is a fully static site deployed on Vercel.

## Development

This project uses [Bun](https://bun.sh).

```sh
bun install
bun run dev      # http://localhost:4321
bun run check    # type-check .astro and .ts files
bun run build    # regenerates the map, then builds to dist/
bun run preview  # serves the built site
```

## Where content lives

| What | Where |
| --- | --- |
| Name, email, social links | `src/config/site.ts` |
| Work history and education | `src/config/experience.ts` |
| Skills | `src/config/skills.ts` |
| Spoken languages | `src/config/languages.ts` |
| Projects | `src/content/projects/*.md` |
| Project screenshots | `src/assets/projects/` |

Years of experience and job durations are computed at build time and refreshed in the browser, so they stay current without a redeploy.

## Adding a project

Create a Markdown file in `src/content/projects/`. The frontmatter is validated by the schema in `src/content.config.ts`:

```yaml
---
title: my-project
summary: One or two sentences on what it is and why it exists.
image: ../../assets/projects/my-project.png # optional
imageAlt: What the screenshot shows # required when image is set
tags: [TypeScript, Astro]
period: '2026'
status: released # beta | in-development | released | archived
statusNote: Optional one-line context shown under the badge
tier: side # flagship | side | experiment
order: 4 # sort order within the tier
links:
    - { label: Repository, url: 'https://github.com/dawichi/my-project', kind: repo }
    - { label: Website, url: 'https://example.com', kind: site }
caseStudy: false # true builds /projects/my-project/ from the Markdown body
---
```

Projects with `caseStudy: true` must have a Markdown body. The build fails if it is empty.

## Travel map

`public/map.svg` is generated by `scripts/generate-map.mjs` before every build. Edit the `visited` set in that script to add countries, then run `bun scripts/generate-map.mjs` or `bun run build`.
